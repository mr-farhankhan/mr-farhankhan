### A short version

I'm **Farhan Khan** — a cybersecurity-focused developer who likes the quiet
side of computing: logs, packets, permissions, and the small details that
decide whether a system holds or folds.

I care about **clarity over cleverness**. Most of what I build starts as a
question I couldn't answer, and ends as a tool I wish existed.

```bash
$ cat ./farhan.conf

  name      = "Farhan Khan"
  role      = "Cybersecurity · Blue Team · Builder"
  mindset   = "defensive first, curious always"
  writes    = ["Python", "Bash", "JavaScript", "SQL"]
  reads     = ["logs", "RFCs", "writeups", "other people's code"]
  avoids    = ["hype", "bloat", "noisy dashboards"]
  currently = "learning in public, one commit at a time"
```

<br />

"Make it work. Make it clear. Make it hard to break."
